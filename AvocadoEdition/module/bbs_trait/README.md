# bbs_trait

캐릭터별 특성을 정의하고 지급하며, 캐릭터 프로필과 `bbs_duel`의 MMB 대련·결투 폼에 표시하는 독립 모듈입니다. Avocado Edition 코어는 수정하지 않습니다.

## 주요 동작

- 특성 슬롯 최대치는 전체 캐릭터 공통으로 기본 5개이며, 기본 3개가 개방됩니다. 슬롯 수를 줄여도 기존 보유 특성은 회수되지 않습니다.
- 상점에서 `특성 슬롯 확장` 유형의 아이템을 판매할 수 있습니다. 아이템 관리에서 사용 여부와 `인벤 사용가능`을 켜고 `영구성`은 끄세요. 캐릭터 인벤토리에서 사용하면 그 캐릭터의 슬롯이 영구히 1개 늘어납니다. 최대치에 도달했으면 아이템은 소모되지 않습니다.
- 상점 또는 인벤토리 선물로 `특성 습득권` 아이템을 지급할 수 있습니다. 아이템 관리에서 기능 종류를 `특성 습득권`으로 선택하고, 연결 특성을 지정하면 됩니다. 아이템은 인벤토리에서만 사용할 수 있으며, 사용 여부·인벤 사용가능·1회용 설정은 저장 시 자동으로 맞춰집니다.
- 빈 슬롯이 있으면 확인 후 연결된 특성을 획득합니다. 슬롯이 가득 찼거나 보유 수가 현재 슬롯보다 많으면, 기존 특성 중 하나를 골라 새 특성과 효과·설명을 비교한 뒤 교체를 확정합니다. 취소하면 아무것도 바뀌지 않고 아이템도 남습니다. 이미 보유한 특성, 비활성 특성, 슬롯이 전혀 없고 교체할 보유 특성도 없는 경우에는 사용할 수 없으며 아이템은 소모되지 않습니다.
- 특성 습득권은 해당 아이템이 들어 있는 캐릭터의 특성을 획득합니다. 인벤토리 선물로 전달할 수 있으며, 받은 캐릭터가 사용해야 그 캐릭터에 특성이 등록됩니다. 상점에서 반복 판매를 막으려면 아이템별 캐릭터 구매 제한을 설정하세요.
- 특성 효과는 최종 점수 보정, 주사위 수 보정, 최저 주사위 재굴림, 받는 피해 보정, 가하는 피해 보정 중 하나입니다.
- 최종 점수·주사위 수·재굴림·가하는 피해 효과는 `스탯 제한 없음` 또는 현재 등록된 스탯 하나를 적용 대상으로 선택합니다. 특정 스탯은 해당 스탯 단독 판정과 그 스탯이 포함된 2스탯 조합 판정에 적용됩니다. 받는 피해는 판정 스탯과 무관합니다.
- 적용 스탯이 삭제된 특성은 전투에서 사용할 수 없으며, 관리자가 현재 등록된 스탯이나 `스탯 제한 없음`으로 다시 지정해야 합니다.
- 게시글당 작성자 캐릭터 특성 하나만 사용할 수 있습니다. HP 효과 특성은 결투에서만 사용할 수 있습니다.
- 주사위 수는 0~100으로 제한하며, 0 이하이면 굴림 결과는 0입니다. 재굴림은 가장 낮은 주사위 하나를 다시 굴려 더 높은 눈일 때만 교체합니다.
- 사용량은 캐릭터·특성·기간별로 기록합니다. 신규 특성의 기본 제한은 기간당 1회이며, 제한 `NULL`은 무제한, `0`은 사용 불가입니다. 성공한 결투 글의 `write_after`에서만 사용량을 기록하며, 글 식별자를 고유 키로 사용해 중복 차감을 막습니다.
- 기간은 KST 기준입니다. 기본값은 월요일 00:00에 시작하는 주간 기간입니다. 시간 주기는 1~168시간으로 설정할 수 있으며, 24시간 이하는 KST 자정 정렬, 24시간 초과는 해당 주기가 활성화된 시점부터 계산합니다. 관리자가 변경한 주기는 현재 기간이 끝난 뒤 적용됩니다.
- 아이콘은 내부 파일 업로드 또는 HTTPS 외부 URL을 사용할 수 있습니다. 외부 URL은 주소만 저장하고 서버에서 다운로드·프록시하지 않으며, 프로필을 보는 브라우저가 외부 호스트에서 직접 불러옵니다.
- 대련·결투 특성은 게시판의 `bbs_trait` 쓰기 설정과 `bbs_duel` 쓰기 설정을 모두 켜야 사용할 수 있습니다. 댓글 특성은 `bbs_trait` 댓글 설정을 별도로 켭니다.
- 관리자는 특성별 `리플 사용`을 허용할 수 있습니다. MMB 댓글은 한 특성만 발현 가능하며 아이콘·이름·설명을 댓글에 스냅샷으로 표시합니다. 댓글 발현은 판정 수치를 바꾸지 않고 사용량만 차감하며, 전투와 사용 횟수를 공유합니다.
- 댓글 특성은 익명으로 사용할 수 없습니다. 댓글 수정으로 발현 특성을 바꾸거나 사용량을 환불하지 않으며, 댓글 삭제도 사용량을 환불하지 않습니다.
- 특성 모듈 1.4.0은 카탈로그와 게시판 write 테이블에 댓글 특성 컬럼을 추가합니다. 모듈 관리자에서 특성 모듈 업데이트/재설치를 실행해 DB 마이그레이션을 적용하세요. 언인스톨은 필요하지 않습니다.
- 1.5.0은 특성 습득권의 중복 사용을 막는 영수증 테이블을 추가합니다. 모듈 업데이트 후 모듈 관리자에서 재설치/업데이트를 실행해 설치 SQL을 적용하세요. 새 코어 컬럼은 추가하지 않습니다.
- 특성 습득권의 영수증은 인벤토리 삭제가 실패하거나 처리 도중 끊겼을 때 같은 인벤토리 아이템으로 특성이 중복 지급되지 않게 합니다. 잔여 아이템이 보이면 다시 사용을 시도해 정리하거나 운영자에게 문의하세요.
- 전투 글 수정·삭제는 이미 기록된 판정, HP, 특성 사용량을 되돌리지 않습니다.
- 슬롯 초과 지급은 교체할 보유 특성을 선택한 뒤 기존·신규 효과를 비교하고 최종 확인하는 두 단계 절차입니다. 중복 보유는 막고, 회수·교체 후에도 사용 기록은 보존합니다.

## 관리자

- `특성 설정`: 기본 개방 슬롯·최대 슬롯 설정과 사용량 초기화 주기를 별도 영역에서 각각 저장합니다. `N시간 값 설정`은 초기화 주기를 `N시간마다`로 선택했을 때 입력할 수 있습니다.
- `특성 목록`: 특성 이름, 아이콘, 설명, 효과, 적용 스탯, 리플 사용 여부, 기간당 사용 제한을 관리합니다.
- `지급·보유 현황`: 캐릭터별 지급·회수·교체 및 현재 보유 현황을 관리합니다.
- `특성 습득권` 연결 정보는 아이템 테이블의 `it_value`에 특성 ID로 저장됩니다. 아이템 관리자에서 연결 특성을 바꾸면 이후 사용부터 새 특성이 적용됩니다. 기존 인벤토리 아이템의 연결도 즉시 바뀌므로, 판매 중 아이템을 변경하기 전에 주의하세요.

업로드한 아이콘은 `data/bbs_trait/`에 저장됩니다. 외부 URL 아이콘은 원본 호스트가 내려가거나 외부 표시를 차단하면 보이지 않을 수 있습니다. 제거·비활성화된 특성도 과거 전투 스냅샷과 사용 기록은 보존합니다.
