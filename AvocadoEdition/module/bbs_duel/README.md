# 대련·결투 (`bbs_duel`)

MMB 글 작성 ACTION에서 판정 스탯과 플레이어 캐릭터 또는 운영자가 등록한 에너미를 선택해 대련·결투합니다. 양쪽의 주사위와 결과를 게시글에 기록합니다.

## 현재 범위

- /adm/ 스탯 설정에 등록된 전체 스탯 이름과 순서로 단일 판정 및 모든 2개 조합을 표시합니다. 조합 판정은 두 스탯 수치를 더한 개수만큼 멀린 D2를 굴리고, 양쪽 합계를 비교합니다.
- 대련: 연습 결투. 결과만 기록하고 HP는 변경하지 않습니다.
- 결투: 무승부는 피해가 없고, 패자에게 HP 피해를 적용합니다. 에너미가 플레이어에게 주는 피해량은 에너미별 설정을 사용하고, 그 외의 피해는 HP 관리 페이지의 기본 피해량을 사용합니다. 대련은 HP를 바꾸지 않습니다.
- 플레이어 상대는 승인된 `main` 또는 `sub` 캐릭터입니다. 현재 작성 캐릭터는 목록에서 제외합니다.
- 플레이어 주사위 개수의 상한은 관리자 에너미 관리 화면에서 1~100으로 설정합니다(초깃값 5). 코어의 실제 스탯 배분 상한과는 별개입니다.
- 에너미는 NPC 캐릭터와 무관한 독립 목록이며, 관리자 페이지에서 현재 등록된 각 스탯 수치(1~100)를 설정합니다. 100은 멀린 주사위 모듈이 한 번에 굴릴 수 있는 최대 주사위 개수입니다.
- 에너미별 허용 판정 스탯은 현재 관리자 스탯 이름으로 직접 입력합니다. 스탯2|스탯3|스탯2+스탯3처럼 |로 허용 항목을 구분하며, 비워 두면 모든 단일·2스탯 판정을 허용합니다.
- HP는 이 모듈 전용 저장소에서 스탯과 독립적으로 관리합니다. 승인된 기존 플레이어 캐릭터는 HP 기능 설치 시 기본 HP로 한 번 초기화하고, 이후 새로 승인되는 캐릭터는 당시 플레이어 기본 HP를 받습니다. 기본 HP 변경은 기존 캐릭터에게 소급하지 않습니다.
- 에너미의 초기 HP가 최대 HP이며, 최대 HP를 수정하면 현재 HP를 유지하되 새 최대치를 넘는 경우에만 낮춥니다. 에너미 표에는 초기/최대 HP와 현재 HP, 플레이어에게 주는 피해량이 표시됩니다.
- HP 관리 페이지에서 플레이어 기본 HP, 전투 기본 피해량과 대상별 현재 HP를 관리합니다. HP가 0이면 전투불능이며, 본인 또는 상대가 대련·결투에 참여할 수 없습니다.
- 결투 결과에는 전투 당시 양쪽 HP와 실제 피해량을 기록합니다. 멤버 프로필에는 현재 HP를 표시합니다.
- **결투·HP 기록** 페이지에서 결투·대련과 운영자 HP 조정 이력을 함께 조회합니다. 기간, 기록 구분, 캐릭터/에너미 이름, 승자로 검색하며 기존 게시글의 전투 기록도 설치 시 이관합니다.
- 이력의 판정수치는 주사위 합계 + 당시 보정값 = 최종값으로 보존합니다. 현재 보정 기능은 없으므로 기존·현재 판정의 보정값은 0입니다.
- HP 변경은 변경 경로와 대상, 변경 전후 값을 남깁니다. HP setter는 `admin`, `item`, `skill` 경로와 간단한 사유를 받을 수 있어 아이템·스킬 구현 시 이력을 연결할 수 있습니다.
- `bbs_duel_damage_adjustment` 필터를 통해 향후 타이틀·성격키워드 보정을 붙일 수 있습니다. 이번 버전에는 보정 규칙을 적용하지 않습니다.
- 에너미 관리표에서 체크한 여러 대상은 표 아래의 전체 저장 버튼으로 순서와 스탯을 한꺼번에 반영할 수 있으며, 행별 수정 버튼도 유지합니다.
- 대상은 한 명이며, 상대 응답 절차는 없습니다.
- 기록 화면은 대련·결투 상대와 판정 결과를 가운데 정렬하고, 양측을 나란한 카드로 표시합니다. 플레이어 캐릭터는 두상과 소속 이미지를 표시하며, 이미지가 없는 소속은 소속명으로 표시합니다. 이미지가 없는 캐릭터나 에너미에도 빈 두상 영역을 유지합니다.

## 설치·사용

1. 모듈을 활성화합니다.
2. 관리자 모듈 페이지의 **에너미 관리**에서 이름, 스탯, 최대 HP, 대플레이어 피해량을 추가합니다.
3. 모듈의 **HP 관리**에서 플레이어 기본 HP와 기본 피해량을 설정하고 대상별 현재 HP를 관리합니다.
4. 자비란 게시판의 모듈 설정에서 `bbs_duel`의 글쓰기 범위를 켭니다.
5. 승인된 본인 캐릭터로 새 글을 작성할 때 ACTION 메뉴에서 대련 또는 결투를 선택하고, 해당 패널에서 판정 스탯과 상대를 고릅니다.
