# bbs_duel 구현 지침

- 공통 규칙은 [`../../docs/module/AGENTS.md`](../../docs/module/AGENTS.md)를 따른다.
- 에너미는 character/NPC 레코드가 아니라 `module_bbs_duel_enemy`의 독립 엔티티다.
- 플레이어 대상은 승인된 `main` 또는 `sub` 캐릭터이며, 작성 캐릭터 자신은 제외한다.
- ACTION의 `DUEL_SPAR` / `DUEL` 토큰을 사용하고 `action_<token>` 패널 ID 규칙을 지킨다.
- 멀린의 주사위 helper를 사용한다. 동일 판정 스탯으로 양쪽을 각각 굴린다.
- 판정은 지원되는 스탯 1개 또는 2개 조합이며, 조합은 개별 스탯 수치의 합만큼 D2를 굴린다. 에너미의 허용 조합은 de_allowed_stats로 제한하고 빈 값은 전체 허용이다.
- 플레이어의 스탯 배분값 0은 최소값으로 대체하지 않는다. 굴림 수가 0 이하면 굴림 없이 점수 0과 주사위 없음 안내를 기록·표시한다.
- HP는 이 모듈 전용 HP 테이블에서 관리하며 코어 스탯·StatusExtra에 저장하지 않는다.
- 대련은 HP를 변경하지 않는다. 결투는 무승부가 아닌 경우 패자 HP를 저장 후 감소시키며, HP 0이면 양측 대상 선택과 작성이 차단된다.
- 기본 플레이어 HP는 신규 승인 캐릭터에만 적용하고, 기존 캐릭터 HP는 HP 관리에서 수동 조정한다. 에너미 최대 HP 변경은 현재 HP를 보존하고 새 상한만 적용한다.
- HP 외부 보정은 `bbs_duel_damage_adjustment` 필터를 거친다. 타이틀·성격키워드 보정 규칙은 별도 합의 후 붙인다.
- 결투·대련 및 HP 변경은 `module_bbs_duel_history`에 기록한다. HP를 변경하는 신규 경로는 `bbs_duel_hp_set_current()`를 사용하고 `admin`/`item`/`skill` 출처와 짧은 사유를 전달해 이력을 남긴다.
- 전투 이력은 당시 주사위 합계·보정값·최종 판정값을 저장한다. 현재 보정 기능이 없을 때 보정값은 0이다.
