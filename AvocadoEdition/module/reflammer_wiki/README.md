# 펜시브 (The Pensieve)

커뮤니티 내부 독립형 위키 모듈. 
관리자 → 모듈에서 **펜시브 (The Pensieve)**를 켜면 전용 테이블과 기본 카테고리를 만들고, 사용자 페이지는 `/module/reflammer_wiki/index.php`, 관리 메뉴는 관리자 → 모듈 → 펜시브에 추가됩니다. 
모듈 카드의 **페이지 보기**로도 이동할 수 있습니다.

- 회원은 문서를 등록하고 수정할 수 있으며, 새 문서와 수정본은 운영진 승인 전까지 공개되지 않습니다. 수정 대기 중에는 이전 공개본을 유지합니다.
- 공개 글은 작성자가 임시 삭제할 수 있고 운영진이 복구할 수 있습니다.
- 작성자는 플레이어명(작성 시점 캐릭터명)으로 표시합니다. 문서의 대상 인물은 작성자와 별도로 자유롭게 입력합니다.
- 대분류·하위분류, 태그 사전, 지정 운영진을 관리자 메뉴에서 관리합니다.
- 이미지는 HTTPS 외부 주소를 저장해 브라우저에서 직접 표시합니다. 서버에 이미지 파일을 내려받거나 저장하지 않습니다. 이미지 파일 주소가 아닌 게시글 페이지 주소는 이미지로 표시되지 않으므로 Tistory 등에서는 실제 이미지/CDN 주소를 사용해야 합니다.
- 검색은 승인된 공개본에서 제목·내용·태그·플레이어명·캐릭터명을 한 필드씩 선택해 찾습니다. 게시글은 제목 가나다순입니다.
- 운영진은 모듈 관리 페이지에서 지정 회원 ID를 추가할 수 있고, 지정 운영진은 위키의 **운영진 검토** 메뉴에서 문서 수정·승인·반려·복구를 할 수 있습니다. 운영자 수정도 승인 전까지 기존 공개본을 유지합니다. 카테고리와 태그 사전 관리는 관리자 모듈 메뉴에서 합니다.
