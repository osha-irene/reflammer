# MMB 기본 썸네일

첨부 이미지나 게시글 이미지 URL이 없는 MMB 글의 왼쪽 이미지 영역에 기본 썸네일을 표시합니다. 결투·행동 로그 본문 안의 소속 아이콘이나 캐릭터 이미지는 변경하지 않습니다.

## 설정

1. 모듈 관리에서 **MMB 기본 썸네일**을 활성화합니다.
2. 적용할 게시판의 모듈 설정에서 **글쓰기**를 켭니다.
3. 모듈의 **썸네일 설정**에서 프로필 항목의 `ar_code`를 입력합니다.

프로필 항목은 `외부이미지 링크` 타입이어야 합니다. 항목은 오너+관리자 공개로 두어도 사용할 수 있습니다. 다만 프로필 항목을 비공개로 설정하더라도 이 이미지는 MMB 게시글의 공개범위에 따라 표시됩니다. 고유코드를 비워 두거나 항목 설정이 유효하지 않으면 소속 아이콘을 사용합니다.

## 우선순위와 보존

1. 게시글 첨부 이미지
2. 게시글 이미지 URL
3. 작성 시점에 읽은 프로필 썸네일 URL
4. 작성 시점의 소속 아이콘 URL

기본 썸네일은 글 작성 시 URL과 출처만 모듈 테이블에 저장합니다. 이미지 파일 자체를 복사하지는 않습니다. 따라서 외부 이미지가 제거되거나 주소가 바뀌면 표시되지 않을 수 있습니다. 프로필 값이 없으면 관리자 소속 설정의 아이콘을 사용하며, 텍스트 대체 문구는 출력하지 않습니다.

기존 글 중 기본 썸네일 저장값이 없는 글은 현재 프로필/소속 설정을 사용합니다. 글을 수정하고 기본 이미지 사용 상태로 저장하면 그때의 주소가 보존됩니다.

성인 블라인드와 멤버 공개는 기존 MMB 글 표시 규칙을 그대로 따릅니다. 이미지 비율은 자르지 않고 유지합니다.
