# 멀린의 주사위 (`bbs_merlin_dice`)

MMB 글과 댓글 작성 시 캐릭터 스탯 하나 또는 두 개를 선택해 D2 주사위를 굴립니다. 각 스탯의 배분 수치를 합한 수만큼 1 또는 2가 나오며, 선택한 스탯명과 주사위별 결과가 기록됩니다. 글/댓글 항목마다 한 번만 굴릴 수 있습니다.

## 설치 및 사용

1. 기본 모듈 `bbs_dice`를 활성화합니다. 이 모듈의 기존 1·2면 이미지와 렌더 설정을 사용합니다.
2. `bbs_merlin_dice`를 활성화합니다.
3. 대상 MMB 게시판의 모듈 설정에서 글쓰기와 댓글을 켭니다.
4. 승인된 캐릭터의 글/댓글 폼에서 멀린의 주사위를 체크하고 스탯을 하나 또는 두 개 선택합니다.

굴림 결과는 `wr_merlin_dice`, 선택한 스탯명은 `wr_merlin_stat`에 저장됩니다. 설치 시 모듈이 게시판 write 테이블에 두 컬럼을 추가합니다. 일반 주사위·액션 처리와 독립적으로 저장됩니다.
